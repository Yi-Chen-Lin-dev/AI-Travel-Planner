# Team setup checklist

- [ ] Private GitHub repository created and initial files uploaded
- [ ] Invite the other two teammates using their confirmed GitHub usernames
- [ ] Each teammate clones the repository
- [ ] Each teammate completes a small branch → commit → push → PR exercise
- [ ] Create a private GitHub Project with Todo, In Progress, Review, and Done
- [ ] Confirm MVP scope and final technology choices
- [ ] Agree on task owners and target dates
- [ ] Configure main-branch protection if available on the account's plan

Prefer one reviewer, resolved conversations, and successful relevant checks before merge. If the plan does not support protection for this private repository, follow the same process by team agreement; do not make the repository public or purchase an upgrade automatically.

The application and automated test suite are not yet implemented. Add CI when real checks exist.
